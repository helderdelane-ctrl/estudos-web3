# Web3 & Trading Automation Labs

Este repositório foi criado para documentar a minha jornada de estudos e o desenvolvimento de soluções práticas combinando **Smart Contracts**, **Automação de Mercados** e **Finanças Descentralizadas (DeFi)**. 

O meu objetivo é consolidar habilidades avançadas de engenharia de software aplicadas ao ecossistema financeiro nos próximos 6 meses.

---

## Stack Tecnológica & Foco de Estudo

### Engenharia de Smart Contracts (Solidity)
- **Foco:** Criação de tokens (ERC-20, ERC-721), gestão de memória (`storage`/`memory`), otimização de Gas e padrões de segurança da OpenZeppelin.
- **Ambiente:** Foundry & Remix IDE.

### Automação & Análise de Dados (Python)
- **Foco:** Desenvolvimento de bots para monitorização de mercados, consumo de APIs de exchanges, cálculo de indicadores de análise técnica (Pandas) e integração com agentes de IA.
- **Ambiente:** Scripts automatizados locais e simulação de ordens (Paper Trading).

### Integração Web3 & Testes (JavaScript)
- **Foco:** Lógica assíncrona (`async/await`), conectividade com a blockchain via bibliotecas Web3 (Ethers.js/Viem) e automação de testes de segurança com Hardhat.

---

## Estrutura do Repositório

- `/bots-python`: Scripts e algoritmos de automação para análise de mercado em tempo real.
- `/smart-contracts`: Contratos inteligentes em Solidity e seus respetivos testes automatizados.
- `/scripts-js`: Ferramentas de integração e leitura de dados *on-chain*.

---

## Regras de Segurança Básicas

Para proteger este ambiente de desenvolvimento:
- Chaves privadas, chaves de API e variáveis de ambiente secretas são geridas localmente através de ficheiros `.env` e estão estritamente listadas no `.gitignore`, prevenindo qualquer exposição pública.
